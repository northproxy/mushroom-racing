# 09 — GitHub Showcase Plan

## What this repository should communicate

A visitor should understand within one minute that this is not merely a “mushroom app”.

It is a project about:

- data modelling;
- geospatial reasoning;
- environmental data;
- explainable scoring;
- Python engineering;
- validation;
- documentation.

## README story

The final README should show:

1. the problem;
2. a map screenshot;
3. an example score explanation;
4. architecture;
5. data sources;
6. validation;
7. current limitations;
8. roadmap.

## Recommended screenshots later

- ranked candidate map;
- one Spot Detail screen;
- rainfall timeline;
- field observation form;
- explanation panel;
- model calibration chart.

## Good portfolio evidence

Examples:

> Built an explainable geospatial scoring model combining forest composition, terrain, geology, weather history and field observations.

> Designed a data pipeline that distinguishes static habitat suitability from dynamic fruiting conditions.

> Added legal-area exclusions and confidence scoring so recommendations expose uncertainty instead of hiding it.

## Avoid

Do not claim:

- AI predicts mushrooms accurately;
- production readiness;
- scientific validation before validation exists;
- live Austrian GIS integration before it is implemented.

## Release strategy

Suggested releases:

- `v0.1.0` — CLI scoring baseline
- `v0.2.0` — geospatial feature extraction
- `v0.3.0` — live weather
- `v0.4.0` — map MVP
- `v0.5.0` — observations + calibration
